# nfs

Pure-Go (CGO=0) NFSv3 server that exports any
[`go-filesystems/interface`](https://github.com/go-filesystems/interface)
`Filesystem`, so every driver in the family becomes mountable on macOS, Linux
and Windows — with no kernel extension, no FSKit entitlement and no cgo.
